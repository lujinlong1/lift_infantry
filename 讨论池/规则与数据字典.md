# 规则与数据字典

## 基本单位

| 类别 | 内部标准 | 边界转换 |
|---|---|---|
| 角度 | `rad` | 遥控显示/调试界面可用 `deg` |
| 角速度 | `rad/s` | 电机反馈 RPM 在设备层转换 |
| 线速度 | `m/s` | 轮 RPM 在底盘运动学边界转换 |
| 时间 | `ms` 或 RTOS tick，字段名必须明确 | 协议时间戳需说明时钟源与回绕 |
| 电流 | `A`；DJI 电调命令保留协议原始量 | 设备层负责换算和限幅 |
| 功率 | `W` | 裁判系统原始字段解析后统一为物理量 |

## 坐标系待确认项

| 名称 | 正方向/定义 | 状态 |
|---|---|---|
| 底盘 `+X` | 车体正前方 | 候选，待实车确认 |
| 底盘 `+Y` | 车体左方 | 候选，待实车确认 |
| 底盘 `+Yaw` | 逆时针 | 候选，待统一 IMU 与电机符号 |
| 自瞄 Pitch/Yaw | 相对误差还是绝对目标角 | 未决定，阻塞自瞄接管 |

## 控制权优先级候选

`硬件/软件故障停机 > 遥控急停/失联 > 裁判系统限制 > 自瞄开火授权 > 操作手命令 > 调试命令`

该顺序尚未形成 ADR。在 `HERO-003` 关闭前，不允许自瞄数据直接绕过统一安全层写电机命令。

## 参数记录格式

每个可调参数至少记录：名称、单位、默认值、合法范围、来源、适用硬件版本、修改日期、验证编号。禁止使用无单位的 `speed`、`angle`、`timeout` 等名称。
